## Contexto

Quem nunca chegou ao mercado e esqueceu justamente o que precisava comprar? Uma lista de compras resolve isso: em vez de guardar cada item separado, você os reúne em um só lugar.

Neste projeto, você vai construir uma lista de compras simples, com três itens informados pelo usuário.

## O que o programa deve fazer

1. Pedir ao usuário **três itens**, um após o outro. Não peça mais nem menos que três.
2. Reunir os três itens em uma lista chamada **`lista_de_compras`**. Essa lista **não pode conter nenhum outro item**, além dos três informados.
3. Exibir a lista na tela.

## Exemplo

Se o usuário informar, nesta ordem:

```
Pão
Leite
Ovos
```

o programa deve exibir:

```
['Pão', 'Leite', 'Ovos']
```

Os itens aparecem **na mesma ordem em que foram digitados** e **exatamente como foram digitados**.

## Pontos de atenção

- **O nome da lista importa.** Ela deve se chamar exatamente `lista_de_compras`.
- **Peça somente três itens.** Nada de perguntas extras.
- **As perguntas que você mostra ao usuário são livres.** Escreva do jeito que preferir.
- **Letras maiúsculas e minúsculas contam.** Se o usuário digitar `Pizza`, o item é `Pizza`, e não `pizza`.

> **Lembre-se:** este projeto é corrigido automaticamente, e computadores são muito literais.
